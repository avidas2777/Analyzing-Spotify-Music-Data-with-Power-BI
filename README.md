# Analyzing-Spotify-Music-Data-with-Power-BI

A Power BI project analyzing Spotify streaming data. Features artist rankings, track popularity metrics, album vs single comparisons, and interactive time-based filters. Built with Power BI Desktop. 

## Overview

This project analyzes Spotify streaming data using Power BI to uncover insights into artist popularity, track performance, and music trends.

## Tools Used

* Power BI
* DAX
* Excel
* CSV Dataset

## Key Features

* Artist ranking analysis
* Track popularity metrics
* Album vs Single comparison
* Interactive filters and slicers
* KPI cards and visualizations

## Files Included

* Spotify-PowerBI-Dashboard.pbix
* Spotify Dataset (.csv)
* Business Requirements Document
* Dashboard Screenshots
